# ハイゴウ！モンスター牧場（仮）

配合を繰り返してモンスターを強くしていく、PCブラウザ向けのアクション配合ゲーム。

- 企画書：[docs/spec.md](docs/spec.md)
- 実装計画：[docs/plan.md](docs/plan.md)

## 開発

```
npm install
npm run dev    # ブラウザで遊ぶ
npm test       # テスト
npm run build  # 型チェック＋ビルド
```

## バトル試遊（ステップ2）

タイトルで Enter → 3体編成でバトル開始。全3ウェーブ（最後はボスの重戦車カブト）。

| 操作 | キー |
|---|---|
| 移動 | WASD または矢印キー |
| 通常攻撃 | J（押しっぱなしで連続） |
| 回避 | K / Space |
| 技1〜3 | U / I / O |
| 交代（左／右の仲間） | Q / E（交代した仲間が登場技を出す） |
| 終了後 | R もう一回 / T タイトル |

敵は攻撃の前に白く光るので、見てから回避できます。

## 遊び方（ステップ3）

1. 牧場で手持ちを確認し、パーティ（最大3体）を組む
2. 出撃先を選んでバトル。勝つと経験値が入り、倒した敵が仲間になりたがることがある（Y で仲間にする）
3. 「配合する」で親を2体選び、引き継ぐ技（2つまで）と特性を選んで子を生む。子は1体目の親の系統になる
4. 新しいステージをクリアすると次のステージが開く。最後は「殻帝の玉座」

データはブラウザに自動で保存されます。
