# 配合モンスターゲーム 企画書（v1.0）

> 仮タイトル：**ハイゴウ！モンスター牧場**（後で決める）
> 前提：PC向け／一人＋Claudeで開発／モンスター絵はAI画像生成／試作は20体
> まずは自分が楽しめるものを作り、良ければ人に遊んでもらう。

---

## 1. コンセプト

**「配合して、ツッコんで、すぐ試す」**

見た目にツッコミたくなる・惚れ込みたくなるモンスターを配合で生み出し、1〜3分のバトルですぐに手触りを確かめる。このループが止まらないゲーム。

大事にすること（優先順）
1. **モンスターの華**：「作りたい」と思える見た目。笑える、気持ち悪い、カッコイイ、の全部に愛嬌がある。
2. **配合の納得感**：生まれた子に両親の面影がある。「そう来たか！」と思える。
3. **配合が活きるバトル**：配合の結果が数字ではなく「動き」の差として体感できる。
4. **テンポ**：育成が配合を待たせない。

## 2. コアループ（1周 5〜10分）

```
 牧場 ──出撃──▶ バトル(1〜3分) ──勝利──▶ 経験値・素材・野良モンスター
  ▲                                              │
  └──── 試す ◀── 配合（子を生む・技を選ぶ）◀──────┘
```

- レベルは速く上がる。低ランクなら数戦で上限近くまで育つ。
- 子は親のレベル合計の一部（例：1/4）を引き継いで生まれる。配合直後でもすぐ戦える。
- 配合するとレベル上限と能力の伸びが上がる（「＋値」）。配合を重ねるほど強くなる。

## 3. モンスター

### 3-1. デザインの基本文法
**「元ネタ × ひねり」**。炊飯器 × マッチョ、寿司 × 力士。
- ひと目で何の掛け算か分かる
- シルエットだけで誰か分かる
- 怖い系・カッコイイ系にも、どこか一つ愛嬌（ポーズ、目つき、小物）を入れる
- ランクが上がるほど装飾・オーラ・サイズが盛られる

### 3-2. 系統（6つ）

| 系統 | 雰囲気 | デザインの方向 |
|---|---|---|
| 日用品 | 道具が筋肉を得た | 家電・道具に手足と筋肉。真顔で全力 |
| 食べもの | 料理が人格を持った | 料理の「らしさ」を職業やキャラに変換 |
| 怪異 | 禍々しい・気持ち悪い | 顔が変、体が巻かれている等。でも律儀 |
| 生きもの | かわいい〜頼もしい | 動物＋装備・趣味 |
| 闘士 | 熱い・カッコイイ | 覆面・肉体美・必殺技の型を持つレスラー |
| 魔王 | 冷たく美しい強さ | 細身の外殻、尾、変身段階。ボス格 |

**カッコイイ系の方針**
- 参考にするのは雰囲気・要素だけで、デザインはすべてオリジナル。
- 魔王系：**なめらかな外殻・光沢・細い尾・冷たい目**。上位ランクになるほど装甲が剥がれてシンプルで洗練された姿になる「変身の逆転」を系統の特徴にする。
- 闘士系：**覆面・マント・肉体美・名乗り**。1体ごとに必殺技の「型」（投げ、関節、空中殺法）を持ち、バトルの登場技として名乗りポーズが出る。

### 3-4. 配合ルール

1. **特殊配合**：レシピの組み合わせなら必ずその子が生まれる。
2. **系統配合**：レシピ外は「父の系統 × 母の系統」の表で、子の系統とランクが決まる（ランクは両親の平均＋α）。
3. **配合前プレビュー**：生まれる子はシルエットで表示。一度生んだ子は図鑑に載り、名前も見える。
4. **継承**
   - 種族固有技 1つ（子の種族で決まる）
   - **親の技から好きな2つを選んで継承**（技スロットは計3）
   - 特性（パッシブ）1つを親から選ぶ。同じ特性を持つ親同士なら強化版に
   - ＋値：両親の＋値の平均＋1。＋値が上がるとレベル上限・能力が伸びる
5. 配合に使った親は牧場からいなくなる（配合の重み）。ただし素材アイテムで「親の分身」を残す救済は後で検討。

### 3-5. 能力値
HP／ちから／まもり／すばやさ／わざ（技の威力と回転）
数値は内部で使い、画面では大きく見せすぎない。差は「動き」で見せる（下記）。

## 4. バトル（3体編成・交代制のリアルタイム）

### 4-1. 画面と基本
- **横から見たアリーナ**（奥行きあり、ベルトスクロールアクション風）。モンスターの全身イラストを大きく見せられる。
- 3体を連れて出撃。プレイヤーは1体を操作、残り2体はAIが動く（作戦：ガンガン／守り重視／技温存、程度）。
- **いつでも交代**。交代で入る側は**登場技**を出す。登場技 → 交代 → 登場技…とつなぐ交代コンボが腕の見せどころ。
- 交代にはクールダウン（例：3秒）。
- 1戦 1〜3分。敵は小型の群れ or 中型1体。ボスでも5分以内。

### 4-2. 操作（PC：キーボード＋マウス、ゲームパッド対応は後で）
| 操作 | キー（案） |
|---|---|
| 移動 | WASD |
| 通常攻撃 | J / 左クリック |
| 回避 | K / スペース |
| 技1〜3 | U / I / O |
| 交代（左の仲間／右の仲間） | Q / E |

### 4-3. 配合の結果がバトルに出る場所

| 要素 | バトルでの違い | 何で決まるか |
|---|---|---|
| 体格（小・中・大） | 速さ、被弾しやすさ、ふっとばされにくさ | 種族 |
| 通常攻撃の型 | 近接連打／溜め／射撃／突進／投げ／空中 | 種族 |
| 技3枠 | 範囲・設置・カウンター・状態異常など固有の動き | 固有1＋親から選んだ2 |
| 登場技 | 交代時に出る技 | 種族 |
| 特性 | 「交代直後は無敵」「仲間が近いと攻撃UP」等 | 親から継承 |

例：ムキメシ（溜め攻撃）に、マキマキの「包帯罠」とネオンクラゲの「電撃床」を継承させる → 罠で止めて溜め攻撃を当てる戦い方が生まれる。

### 4-4. テンポの工夫
- 勝利時の経験値は控えも含めて3体全員に入る
- 負けても経験値の半分はもらえる
- 「もう一回」ボタンで同じ敵にすぐ再挑戦（配合した子のテスト用）

## 5. 絵（AI画像生成）の作り方

- **1体につき全身1枚**（透過PNG、横向き）を基本にし、アニメーションは**プログラムで動かす**（伸び縮み、傾き、跳ねる、残像、エフェクト）。AI画像はコマ送りアニメの統一が難しいため。
- 画風を揃えるため、共通のプロンプトの型を作る（線の太さ、塗り、背景なし、横向き、全身）。参考画像（スタンプ）の「太めの線・やや劇画寄りの塗り」をベースにする。
- 魔王・闘士系は同じ型で「光沢・陰影強め」の追加指示を入れる。
- 試作の初期は**仮の図形**でバトルを作り、絵は並行して差し替える。
